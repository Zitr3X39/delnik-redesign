# Дельник v2 — дизайн-система

> Статус: направление утверждено владельцем 2026-08-10.
> Код: `lib/ui_v2/`. Старый UI (`lib/theme`, `lib/screens`) не трогаем до влития.

## Принципы

1. **Структура Авито, характер свой.** Нейтральный фон, белые карточки, плотные
   списки, фото-якорь, цена крупно. Но не бледная копия: тёплый оранжевый акцент
   (Авито — синий, Яндекс — жёлто-чёрный, Дельник — оранжевый), мягкие градиенты
   на CTA и «горячих» тегах, живые микро-анимации.
2. **Один ритм.** Радиусы 8/12/16/24, отступы кратны 4. Никаких ad-hoc значений
   в компонентах.
3. **Токены, а не hex.** Все цвета — через `AppColorsExt` (ThemeExtension).
   Тёмная тема — тот же код, другие значения токенов.
4. **Контраст по-честному.** Основной текст ≥ 4.5:1. Акцентный текст —
   затемнённый `orange700`. На оранжевой заливке — тёмный текст
   (как Яндекс на жёлтом): белый на оранжевом не проходит WCAG.
5. **Один тап — одно действие.** В карточке две зоны: вся карточка → детали;
   сердце 44×44 → избранное. Никаких вложенных тапов внутри тапа.

## Типографика

Шкала: 28 / 22 / 20 / 17 / 16 / 15 / 13 / 11. Цена — 20px w800 с табличными
цифрами (`FontFeature.tabularFigures`), чтобы колонки цен не плясали.

Сейчас в коде `NotoSans` (уже в assets). Целевая пара — **Manrope** (UI) +
**Unbounded** (онбординг, пустые состояния, лого-слово): обе с полной
кириллицей, обе не в бан-листе (Inter/Roboto/Arial/system). Файлы кладём
локально в `assets/fonts/`, без Google Fonts CDN. Отдельная задача.

## Моушн

- Длительности: 150 (микро) / 250 (обычные) / 400 (переходы), выходы ~60% от входов.
- Кривые: `easeOutCubic` на вход, `easeInCubic` на выход.
- Стаггер списков 30–50 мс на элемент.
- Тап по карточке — scale 0.985 с возвратом.
- Анимируем только transform/opacity. Не блокируем ввод.
- Уважаем системный reduced-motion и масштаб шрифта: `textScaler` НЕ зажимаем
  (старый `clamp(maxScaleFactor: 1.0)` в v2 не переезжает).

## Карточка заявки (JobCardV2)

```
┌──────────────────────────────────────────────┐
│ ┌────────┐  1 500 ₽/час                  ♡   │
│ │ фото   │  Разгрузить фуру, 2 часа          │
│ │ 96×96  │  2,4 км · Ленина, 12              │
│ │ [Срочно]│  Сегодня 18:00 · осталось 2 из 5 │
│ └────────┘  Игорь · 4,8 ★                     │
└──────────────────────────────────────────────┘
```

- Цена — первая строка, 20px w800, табличные цифры.
- Заголовок — максимум 2 строки.
- Всё, что в старой карточке было плашками (4 разных стиля, 4 радиуса),
  становится обычным серым текстом через `·`.
- Единственный цветной элемент — тег «Срочно» на градиенте, в углу фото.
- Пустое фото → плитка с глифом категории на `placeholderGradient`, не дырка.
- Состояния: `open` / `full` («Набрано») / `closed` («Закрыто»).
  Не-открытые карточки затухают до 55% opacity. Заявка, набравшая места,
  НЕ выдёргивается из-под пальца — сначала переходит в `full`, исчезает
  с задержкой по правилам модели (`isVisibleTo`).
- «Осталось последнее место» — акцентный текст, единственный повод
  выделить строку меты цветом.
- Компонент чистый: принимает строки и колбэки, не знает про `Job` и
  провайдеры. Адаптер `Job → JobCardV2` живёт рядом с экранами.

## Что НЕ делаем (анти-слоп)

- Никакого стекла и блюра в ленте — `glass.dart` под удаление при влитии.
- Никаких градиентных фонов приложения.
- Никаких emoji в роли иконок; одна иконочная семья, один скругление.
- Никаких Inter/Roboto/Arial/system UI.
- Не зажимаем `textScaler`; доступность чиним вёрсткой, а не капом шрифта.
- Не копируем фирменные цвета Авито/Яндекса — берём структуру, не айдентику.

## Решения, зафиксированные 2026-08-10 (грилинг)

1. Экраны не рефакторим — слой данных вытаскиваем в `data/repositories`
   как есть, UI пишем с нуля; `lib/screens` под замену.
2. Градиент «небо» уходит из основной темы.
3. Тёмная тема — сразу, парой токенов.
4. Шрифты — локально в assets, без CDN.
5. `textScaler.clamp(1.0)` снимаем.
6. Роутинг — go_router, `usePathUrlStrategy()`, авторизация через `redirect`.
7. Анонимный ключ Supabase → `--dart-define` при переезде на свой инстанс.
