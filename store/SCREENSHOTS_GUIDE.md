# Шаг 3 — Скриншоты для RuStore

## Требования RuStore
- Минимум **2** скриншота, лучше **4–8**.
- Формат: PNG или JPG.
- Телефон (портрет): рекомендую **1080×1920** (соотношение 9:16).
- Без реальных персональных данных на экранах (чужие телефоны/ФИО).

## Какие экраны снять (порядок = порядок в карточке)
1. Онбординг (красивый первый экран).
2. Лента заявок / карта.
3. Карточка заявки.
4. Создание заявки.
5. Чат.
6. Профиль с рейтингом и отзывами.

## Как снять — 3 способа

### А) На телефоне (самый простой)
Установи свежий APK, походи по экранам и делай скриншоты
(Громкость вниз + Питание). Современные телефоны дают ~1080×2400 —
это подходит.

### Б) В браузере (если тестишь web-версию)
1. Открой сайт, нажми **F12** → иконка телефона/планшета (Toggle device toolbar).
2. Выбери Responsive и выставь размер **1080×1920** (или 540×960 с DPR 2).
3. В меню (⋮) DevTools → **Capture screenshot**.

### В) Эмулятор Android Studio
Запусти эмулятор Pixel, поставь APK, кнопка «Фотоаппарат» в панели эмулятора.

## Советы по качеству
- Заполни ленту парой тестовых заявок, чтобы экраны не были пустыми.
- Одинаковый размер у всех скринов — аккуратнее смотрится.
- Первый скрин — самый привлекательный (он виден в поиске).
