# ДЕЛЬНИК — чек-лист защиты (v62)

Коротко: 100%-й защиты не бывает, но эти шаги закрывают ~95% реальных угроз для MVP. Почти всё бесплатно.

---

## ЭТАП 1 — СЕЙЧАС (можно тестировать с кнопкой «Тест вход»)

Кнопка «Тест вход» ПРОДОЛЖАЕТ работать — ничего из этого этапа её не ломает.

### Supabase -> SQL Editor -> New query -> Run (по порядку)
1. `sql/08_security_hardening.sql` — запрет отзыва самому себе.
   Блок «боевой режим» в нём специально ЗАКОММЕНТИРОВАН — не трогай его пока.
2. `sql/09_cleanup_orphan_jobs.sql` — автоудаление заявок мёртвых/вышедших аккаунтов.
   Требует расширение pg_cron: Database -> Extensions -> включить `pg_cron`.
   Если pg_cron не хочешь — можно разово: `select public.cleanup_orphan_jobs();`
3. `sql/10_rate_limits.sql` — серверные лимиты (щедрые, тестам не мешают):
   - заявки: 10 новых / 24ч
   - отзывы: 30 новых / 24ч
   - сообщения: 30 / минуту (антифлуд)

### Supabase -> Authentication -> Rate Limits (защита от SMS-бомбинга и брута)
- Уменьши лимит отправки OTP / подтверждений до разумных значений
  (важно перед подключением реальных СМС — чтобы не сжигали деньги).

### Cloudflare (защита сайта — уже работает автоматически)
- L3/L4 DDoS-защита включена по умолчанию (бесплатно), настраивать ничего не надо.
- На случай атаки: Security -> Settings -> Under Attack Mode (одна кнопка).

---

## ЭТАП 2 — ПЕРЕД ПУБЛИКАЦИЕЙ В СТОРЫ (боевой режим)

1. **Убрать кнопку «Тест вход»** из `lib/screens/auth_screen.dart`
   (метод `_testLogin` = `signInAnonymously()` — главная дыра).
2. **Supabase -> Authentication -> Providers -> Anonymous -> выключить.**
3. **Включить «боевой режим»** в `sql/08_security_hardening.sql`
   (раскомментировать нижний блок и Run) — запрещает любую запись анонимам.
4. Подключить реальный вход по СМС (отдельный большой этап).

---

## Чего НЕ надо бояться (частые мифы)
- `anon` ключ виден в APK/web — ЭТО НОРМА. Он публичный по замыслу.
  Защищает не он, а RLS + эти триггеры.
- Главное правило: **клиенту нельзя доверять.** APK декомпилируется,
  поэтому все ограничения — на сервере (RLS + эти триггеры).
